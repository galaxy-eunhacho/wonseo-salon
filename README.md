# 📖 WONSEO SALON VOCA NOTES (원서살롱 어휘 노트)

원서살롱 멤버 전용 프라이빗 어휘 노트 & 플래시카드 웹 애플리케이션입니다.

- **배포 주소**: [https://wonseo-salon.netlify.app/](https://wonseo-salon.netlify.app/)
- **주요 기능**:
  - 멤버별 로그인 및 원서별(American Hagwon 등) 접근 권한 제어
  - 챕터별 어휘 목록(List) 및 플래시카드(Card) 스와이프 학습 모드
  - 고품질 미국 영어 Web Speech API (TTS) 원어민 발음 듣기
  - Supabase 연동 데이터 로딩 및 상태 자동 저장/복원
  - 실시간 통합 키워드 검색
  - 모바일 터치 최적화 UI/UX
